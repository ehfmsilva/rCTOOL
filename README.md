# rCTOOL documentation website

Documentation for **rCTOOL 3.1.0**, built with pkgdown and published at **https://ehfmsilva.github.io/rCTOOL/**.

The website follows the documentation layout of the paar package and uses the supplied rCTOOL logo. It includes installation instructions, three executed tutorials, function documentation, citations, and site search.

## Source and updates

The complete website source and generated pages are in [rctool-website.zip](rctool-website.zip). Extract the archive, open the rctool-website directory, and follow scripts/BUILDING.txt to rebuild it. The generated website is in docs/.

GitHub Actions extracts the archive and publishes docs/ to GitHub Pages whenever the archive or deployment workflow changes on main. Upload an updated archive to publish a new version.

This repository hosts the documentation website. The upstream R package is developed at [francagiannini/rCTOOL](https://github.com/francagiannini/rCTOOL) and is available on [CRAN](https://CRAN.R-project.org/package=rCTOOL).

The package source is based on the CRAN 3.1.0 snapshot (commit 10cf1b8717ea3173a6979c25764af1598a22c747 of cran/rCTOOL). Copyright and MIT license information are retained in the archive.
